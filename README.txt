Study Tracker Ver.2.3 / GitHub Pages

Ver.2.2の全機能を維持し、週報の「AI用にコピー」プロンプトを更新しました。

追加するAI出力:
○ 小さな成長、成果を感じた点
- 1週間の学習記録から客観的に読み取れる小さな前進を1〜3点
- 学習量、継続、範囲、気づきの変化などを根拠にする
- 記録にない成果は推測しない

○ 次週の120点目標
- 今週を100点とした場合の、少し背伸びすれば達成可能な目標を1〜3点
- 時間、回数、範囲、行動を可能な限り数値化
- 単純に学習時間を20%増やす意味ではなく、質・量・継続性から設定

GitHubではZIP内のindex.htmlを既存index.htmlへ上書きしてください。
バックアップ・復元機能はそのまま利用できます。
