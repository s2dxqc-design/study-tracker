追加機能: 学習記録の修正

履歴画面で各記録に「修正」「削除」が表示されます。
「修正」を押すと記録画面へ既存値を読み込み、以下を変更できます。
- 教材
- 学習内容
- 学習日
- 学習時間
- メモ・気づき

「変更を保存」で同じ記録を更新します。新しい記録として重複追加されません。
修正後、Dayカウント、日/週/月集計、カレンダー、教材別グラフ、週報へ自動反映されます。

Ver.2.3のバックアップ・復元、週報、AI用コピー機能は維持しています。
GitHubではindex.htmlを上書きしてCommitしてください。
